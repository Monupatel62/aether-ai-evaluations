# Research and Licenses — aether-ai-evaluations

## Evaluation areas
- Deterministic unit/contract checks vs. probabilistic model-judge evaluation.
- Dataset versioning, artifact storage, reproducibility, and regression reporting.
- License and provenance for any imported benchmark dataset.

## Review requirements
Every external dataset or evaluator dependency requires provenance, license/terms, redistribution restrictions, privacy review, version pinning, and a documented owner. Do not copy benchmark data without verifying permission.
